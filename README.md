React Learning

A hands-on collection of React.js concepts and practical coding examples developed while learning React.

Topics Covered

1. JSX and Components – Creating reusable UI components.
2. Props – Passing data between components.
3. useState – Managing component state.
4. Events and Conditional Rendering – Handling user interactions and dynamic UI.
5. Lists and Keys – Rendering dynamic lists using JavaScript arrays.
6. useEffect and API Integration – Fetching and displaying external API data.
7. Forms and Input Handling – Managing user input and form submissions.
8. React Router – Implementing navigation between pages.

Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

Getting Started

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project directory:

cd React

Install dependencies:

npm install

Start the development server:

npm run dev

Open the localhost URL displayed in the terminal.

Purpose

This repository showcases my learning journey with React.js through practical examples, experimentation and hands-on implementation of its core concepts.
